# Фичи

Планируемый набор доп-фич. Реализация — на C++ и/или [[Python SDK|плагинами]].

## Планируется
- [[ghost-режим]] — не отправлять статусы «прочитано/онлайн».
- Фичи сообщений — правка/дополнение поведения (см. [[Швы|seam.update-dispatch]]).
- Кастомизация UI — темы, стили, раскладка.
- RU-локализация — приоритетный язык.
- Ускорение загрузок — параллелизм/буферы.
