# SEAMS.md

Реестр «швов» — единичных точек внедрения в апстрим-код tdesktop. Цель: держать
диффы с апстримом минимальными и переприменять их вручную после merge с `upstream`.

Формат записи:

```
## <идентификатор>
- Файл: <путь>
- Якорь: <функция/контекст в коде>
- Вызов: <что добавляем>
- Назначение: <зачем>
- Проверка: <как убедиться, что работает>
```

## seam.update-dispatch

- Файл: `tdesktop/Telegram/SourceFiles/api/api_updates.cpp`
- Якорь: `Api::Updates::mtpUpdateReceived(const MTPUpdates &updates)`
- Вызов: `Extra::Hooks::OnUpdate();` первой строкой тела функции.
- Назначение: единая точка приёма входящих апдейтов на главном потоке; отсюда
  в дальнейшем будут вызываться C++-фичи и движок плагинов.
- Проверка: в главном логе появляется одна строка `XunGram: update hook active`
  при первом полученном апдейте. Поведение клиента не меняется.

Зависимость: заголовок `extra/seam/hooks.h`, реализация `extra/seam/hooks.cpp`.
Тип `Extra::Hooks::OnUpdate` сейчас без параметров; полезная нагрузка (сам `MTPUpdates`)
будет добавлена на вехе M2.1, когда появится публичный API плагинов.

## seam.app-startup

- Файл: `tdesktop/Telegram/SourceFiles/core/application.cpp`
- Якорь: `Core::Application::run()`, после `Storage::ClearStaleArchiveFiles();`
- Вызов: `Extra::Initialize();`
- Назначение: однократная инициализация слоя XunGram на главном потоке после
  поднятия Qt-приложения и локального хранилища (обнаружение плагинов, движок).
- Проверка: в главном логе появляется `XunGram: found N plugin(s)`.
  При пустом каталоге плагинов поведение клиента не меняется.
- Зависимости: `extra/extra.h` → `extra/host/engine.*` → `extra/host/manifest.*`.
